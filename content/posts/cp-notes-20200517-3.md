贪心，每个数字只用一次，从前往后扫一遍即可。

想复杂了，最简单的就是最好的。

```
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
int main() {
    ll T, a;
    cin >> T;
    while (T--) {
        cin >> a;
        ll cnt = 0;
        for (ll i = 1; i <= a; ++i)
            if (a % i == 0) a /= i, ++cnt;
        cout << cnt << endl;
    }
    return 0;
}
```

---

感谢牛友Else201812241649867指正，上面的做法是错的，如果n是一个大质数就会T，所以我们对上面的做法稍作修改：

1. 大质数$x$只能表示成$x=1*x$
2. 完全平方数$x$也只能表示成$x=1*x$

所以我们其实可以得到一个结论，对于任意的$x$，其最优展开式有且只有一个数大于$\sqrt{x}$

所以只需要对$\sqrt{x}$范围内讨论即可

```
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
int main() {
    ll T, a;
    cin >> T;
    while (T--) {
        cin >> a;
        ll cnt = 1;//唯一的大于根号a的数
        for (ll i = 1; i*i < a; ++i)
            if (a % i == 0) a /= i, ++cnt;
        cout << cnt << endl;
    }
    return 0;
}
```
