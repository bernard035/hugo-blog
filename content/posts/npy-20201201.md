其实就是要找最长的一段不含有n或p或y的字串长度。

可以用双指针维护但其实并没有必要。

```
class Solution:
  def Maximumlength(self , x ):
    n = x.split('n')
    p = x.split('p')
    y = x.split('y')
    ans = 0
    for i in n:
      ans = max(len(i), ans)
    for i in y:
      ans = max(len(i), ans)
    for i in p:
      ans = max(len(i), ans)
    return ans
```
