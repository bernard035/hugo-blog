本题和<https://ac.nowcoder.com/acm/contest/5758/F> 一模一样。

显然是斐波那契。不能构成三角形的极限情况必然是$a+b==c$。

```
class Solution {
   public:
    /**
     *
     * @param a long长整型 木棒的长度
     * @return int整型
     */
    int stick(long long a) {
        long long b = 0, c = 1, i = 0;
        while (c <= a) {
            a -= c;
            c += b;
            b = c - b;
            ++i;
        }
        return i;
    }
};
```

随便递推一下都行。
