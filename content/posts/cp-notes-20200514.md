## 题目大意

![图片说明](/images/3f9d655d3a7b863e.png "数轴")

在起点为a，终点为b的滑道上，有两个长度为t小滑块随机滑动（可重叠） ，问它们重叠的概率。

## 分析

a,b是无用信息，设 $L=b-a$ ，当$t$特别大，超过$L$时，第二个滑块无处可放，必定重叠。

![图片说明](/images/757889798748c9d2.png "必定重叠")

对于一般情况，另外分析：  
我们把二者的数轴分离，即建立平面直角坐标系，设$x$为小滑块甲的起始坐标，$y$为小滑块乙的起始坐标。

当二者重叠时，满足$|y-x|\leq t$ ，即建立如下坐标系，完成线性规划。

![图片说明](/images/4247d5da5994c550.png "线性规划")

知可行域内面积为整个正方形面积减去两个三角形面积，即$S=L^2-t^2$，概率$P=S/L^2$。

即解。

## solution

```
#include <bits/stdc++.h>
using namespace std;
const double eps = 1e-6;
int main() {
    int T;
    double a, b, t;
    scanf("%d", &T);
    while (T--) {
        scanf("%lf%lf%lf", &a, &b, &t);
        double L = b - a;
        if (L - t < eps) printf("1.00000\n");
        else printf("%.5lf\n", 1 - (L - t) * (L - t) / (L * L));
    }
    return 0;
}
```
